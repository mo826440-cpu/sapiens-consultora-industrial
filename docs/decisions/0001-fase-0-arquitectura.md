# ADR 0001 — Arquitectura aprobada (Fase 0)

Fecha: 2026-09-19

## Contexto

Se necesita una aplicación interna para seguir el proyecto Sapiens Industrial.

## Decisión

- SPA Vite + React + TypeScript.
- Bootstrap 5 + react-bootstrap + tema industrial.
- Supabase como único backend.
- Un rol por usuario.
- Sin tabla `projects` en el MVP.
- Usuarios iniciales creados desde el panel de Supabase.
- Avance de etapa por promedio de ítems y tareas, peso igual.
- Tabla `notifications` en el esquema; UI posterior.
- Commits Conventional Commits en español.

## Estado

Aprobado por el titular del proyecto.
